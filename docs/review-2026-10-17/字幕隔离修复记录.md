# 字幕文档隔离与切页恢复

2026-10-17。只修字幕工作台；保留现有可见布局、操作文案和后端契约。

## 修复内容

- `subtitle:cue` 必须带当前文档ID且行号为整数。其他文档、缺失ID的事件不修改列表，也不触发快照读取。
- 每次成功导入建立独立文档作用域。文档快照、编辑返回值与样式请求必须仍属于该作用域，快照自身ID也必须匹配。
- 同一文档的快照按请求版本验收；较早请求即使较晚返回，也不能覆盖较新结果。新cue事件使事件前发出的快照失效。
- 导入结果按导入请求版本验收；切换文件清理旧计时器和编辑临时状态；迟到编辑结果不清除新文件选中项。
- 队列操作及取消后的延迟刷新保留原文档作用域；旧操作完成后不对新文档刷新或显示旧错误。
- 字幕页在外壳中保留实例，切换到其他页时使用`hidden`隐藏。文档、选中行、阅读位置、语言与导出选项、未提交草稿得以保留，后台事件仍正常接收。
- 隐藏字幕页的Modal门户、右键菜单和Esc监听受`active`约束，避免覆盖其他页面。

不包含跨重启恢复、其他页面会话保持、输入法提交、撤销功能或后端任务版本协议。

npm run build
