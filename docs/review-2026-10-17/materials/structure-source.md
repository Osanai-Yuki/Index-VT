# 回声引擎操作说明

只有在校验通过后，才能开始安装。下载完成不等于安装完成。

| 状态 | 数量 | 说明 |
|---|---:|---|
| 已完成 | 17 | 不应重新翻译 |
| 失败 | 3 | 仅重试这三项 |

1. 打开 `config.json`。
2. 保留变量 `user_id` 和占位符 `{{model_name}}`。
3. 不要修改下面的代码块或 URL。

```json
{"user_id":2048,"verified":false,"path":"C:\\models\\echo.gguf"}
```
