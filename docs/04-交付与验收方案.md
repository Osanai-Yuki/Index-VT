## 3. 性能验收

| 指标 | 条件 | 阈值 | 测量方法 |
|---|---|---|---|
| 首 token 延迟（TTFT） | Q4_K_M @ RTX 3060 级，输入 ≤100 token | ≤ 800ms | 前端记录提交→首个 delta 事件 |
| 生成吞吐 | 同上，输出 ≥200 token | ≥ 30 tok/s | 服务端 usage/秒或前端计数 |
| 模型切换 | Q4_K_M 任意两模型 | ≤ 15s | 点击"设为当前"→ 新模型 `/health` 通过 |
| 空闲唤醒 | 休眠态 → 新任务完成 | ≤ 15s [assumption] | F-13 顺带测量 |
| 字幕队列吞吐 | 短句（≤40 字）5000 cue | ≥ 5 条/s [assumption] | 队列总时长 / cue 数 |
| 长稳 | 连续 100 次翻译 + 3 次切换 + 2 次字幕任务 | RSS 增幅 ≤ 5%、VRAM 无持续增长 | 前后对比 `Get-Process` 与 `nvidia-smi` |
| 启动 | 冷启动到主界面 | ≤ 2s [assumption] | StopWatch |

> `[assumption]` 指标在 M2 实测后修订本表并通知评审。

## 4. 环境验收

### 4.1 干净 Win11 全新安装路径（F-10 展开为操作清单）

1. 全新 Win11（仅装 NVIDIA 驱动，无 Python/conda/VS 运行库）复制便携目录 → 双击 Index-VT.exe。
2. 单实例锁验证（F-20）→ 首次引导启动。
3. 环境检测页正确识别 GPU 型号/显存；WebView2 缺失时给出 offline installer 引导（Win10 1809 以下场景）。
4. 下载 Index-Translate-2B Q4_K_M（真实网络，记录耗时）。
5. 试译一句话 → 成功 → 主界面。**全程 ≤ 10 分钟、≤ 5 步人工操作 [assumption]。**

### 4.2 降级路径

- 无 NVIDIA GPU：CPU 模式全流程可走通；横幅与任务耗时提示如实标注。
- 4GB 显存：自动部分层卸载提示；F-01 仍通过（速度放宽为 CPU 档不做硬性要求）。
- 磁盘 < 4GB：下载前拦截并提示。

## 6. 回归冒烟清单（每里程碑出口必跑，≤ 10 分钟）


## 7. 缺陷分级与验收裁决

- **S1 阻塞**：★ 用例失败、崩溃、数据丢失（历史/字幕文件损坏）→ 不得发布。
- **S2 严重**：非 ★ 用例失败、性能指标超阈 20% → 修复后复验该组用例。
- **S3 一般**：文案/视觉与设计稿偏差、非关键提示缺失 → 记录后允许发布，下版修复。
- 裁决记录写入 `.archcore/plans/index-vt-plan.md` 对应里程碑段（追加验收结论）。
