### C2. 配音模型用通用提示词驱动

- **影响**：两模型的领域特性在 UI 上发挥不出。
- **处置**：后续里程碑（分发逻辑按 `translator.ModeKind` 已就绪，缺前端选择面）。

### C3. 状态栏「离线可用」徽标是静态元素
- **现状**：徽标写死显示（`StatusBar.tsx:93`）；Go 侧 `GetSystemStatus` 的 `Offline` 字段恒为 `false`（`app.go:646`）且前端无人消费——**断网探测并未实现**。徽标只是把「模型就绪后不需要网络」这句设计事实常驻显示。
- **影响**：用户可能误读为实时断网状态。
- **处置**：要么实现探测（断网时本地推理照跑、下载失败即离线），要么改文案为「本地推理」，排期时定。

### C4. 模型激活收口只在 UI 层
- **现状**：模型中心已放开「文件已登记即可设为当前」（`ModelHub.tsx:200` 起），但后端 `SetActiveModel` 本身没有守卫——绕过 UI 直接调用仍可设置任意模型（含未登记路径）。
- **影响**：只有直接操作绑定层的调用方受影响，正常 UI 路径无风险。
- **处置**：后端补登记校验可作健壮性小项，非阻塞。

### C5. 设置页「关闭程序时」是单选展示
- **现状**：无 `onChange` 的单选组——「退出即释放」是唯一实现；`config.Resource.CloseBehavior` 无其他分支。主题与字号则已真正可改并持久化（`Settings.tsx:163`，存 localStorage + 配置 `appearance`，重启保持）。
- **影响**：关闭行为不可配置（目前无其他行为可选）。
- **处置**：若未来加「常驻」选项再接线；当前如实展示不算缺陷。

## E. 性能与测量的未定项

1. **64K 档（`-c 65536`）真机未测**：模型 GGUF 标称 262144 positions（理论支持），但启动耗时、显存峰值、失败时 orchestrator 退避从未实测；`-c` 自定义刚落地时，建议首次用超 32K 档时手工观察一次。
2. **显存估算是线性模型**（`vramestimate.EstimateCtxVRAM` 的 `basis` 字段如实标注）：偏差 ±20%，不是测量值；F-08b 的「64K 需 12GB+」提示按估算式给出。
3. **大文件边界**：字幕 `MaxSubtitleBytes` 32MB（`engine.go:18`，B29 有意设计——防误选整本小说）、长文档单卷 50000 字（超限有明确 toast 提示）。两者均有友好报错，属设计边界非缺陷。
4. **日志内容随级别变化**：`logs/llama-server.out.log` 默认不进「一键收集打包」的脱敏 zip（`app/logs.go:15`）——实测样本 25 行只有启动信息无正文，但 `-lv` 级别提高后的行为未实测；该日志含模型绝对路径，分享 zip 时等于交出本机目录结构，默认排除是正确选择。

## F. 工程与测试约束

1. **`go test -race` 不可用**：`CGO_ENABLED=0` 是架构决策（ADR-001），竞态类修复只能靠确定性并发测试 + 代码审阅。**任何报告不得声称 race detector 通过**。
2. **playwright chromium 本机不可达**（`cdn.playwright.dev` 超时）：各 verify 脚本内置回退 `channel: 'chrome'` → `msedge` → 自带 chromium，不依赖浏览器下载；这段回退在每个脚本里各存一份，没有抽公共 helper。
3. **Git Bash 跑 node 门禁脚本需 `MSYS_NO_PATHCONV=1`**：只有 `verify-a11y.mjs` 的位置参数 `/?primitives` 会被 MSYS 路径转换吃掉；npm scripts 走 cmd 则不需要。
4. **真机自动化（2026-10-09 首轮实测）**：(a) 沙箱文件防护会拦 WebView2 写 `%APPDATA%\<exe>\EBWebView\lockfile`，自动化启动 exe 需设 `WEBVIEW2_USER_DATA_FOLDER` 到可写目录（正常用户环境无此问题）；(b) `wails dev` 浏览器模式（34115）下原生文件对话框触发 go-webview2 errorCallback 并退出 dev 进程，打包 exe 的 WebView2 窗口无此问题；(c) WebView2 内容树对 Windows UIA 完整暴露，UIA 是本机驱动真机 UI 的可行路径；(d) PowerShell 7 写 `.ps1` 交 Windows PowerShell 5.1 执行必须 UTF-8 BOM，否则中文串会吞掉引号。

## Z. 已解除的发布阻塞项

### A1. JetBrains Mono 许可证副本缺失（已解除，但原处置方案是错的）

- **现状（已修）**：内嵌字体三份均 SIL OFL 1.1 —— 修复当时的组合是 Archivo latin 子集 18.3KB、
  Noto Sans SC CJK 子集 1.72MB、JetBrains Mono latin 子集 30.7KB；**v2.2 起拉丁与等宽已换为
  Public Sans（26.1KB）与 Geist Mono（33.8KB）**，中文不变。
  三份许可证文本随产物分发：`frontend/public/licenses/OFL-{PublicSans,NotoSansSC,GeistMono}.txt`。
- **原处置方案有误（务必不要照做）**：本条原写「放入 `frontend/src/assets/fonts/`（随 `assets` 打入前端产物）」
  ——**这是错的**。那个目录里的 `.txt` 没有被任何模块 `import`，Vite 只打包被引用到的资源，会**静默丢弃**。
  修复前 `app/frontenddist/` 里只有 3 份 woff2 + js + css，**没有任何许可证文本**：
  字体随 exe 分发、许可证没有，OFL §2「每一份拷贝都要带上版权声明与本许可证」当时并不满足。
- **正确做法**：放 `frontend/public/`（Vite 原样拷贝到 `dist` 根 → 被 Wails 嵌入 exe）。
  OFL §2 允许三种载体（独立文本文件 / 可读头 / 机器可读元数据），条件是「**能被用户轻易看到**」；
  单文件 exe 里用户打不开 woff2 的 `name` 表，所以机器可读字段这一路走不通，必须落成独立文本文件。
- **影响**：原为真实合规缺口（非理论风险）；现由门禁锁住。
- **回归锁**：`verify:theme` #11（断言 `dist/licenses/` 三份齐全，且各自含 OFL 正文与对应版权行）、
  #12（换字体时的许可证审计闸门：`@font-face` 族名必须已在审计表登记，否则门禁红）。

**要点澄清（曾经被误解）**：OFL 1.1 **本来就允许商用**，且明确授予
"use, study, copy, merge, **embed**, **modify**, redistribute, and **sell**"。
所以「换成授权更宽松的字体」这条路上**没有可获得的授权减免**——OFL→Apache-2.0 反而多一条 `NOTICE` 义务，
OFL→厂商 EULA（MiSans / HarmonyOS Sans / OPPO Sans / 阿里巴巴普惠体 / Fontshare 等）义务更重且条款不可控。
本项的真实收益是**可证明的合规**（许可证确实随产物分发 + 保留字体名逐份核过），不是换字体。

**顺带修掉的两个真缺陷**：

1. 三份子集的 `name` 表族名是**错的**——CJK 那份叫 `Noto Sans SC Thin`、Archivo 那份叫 `Archivo SemiBold`，
   而两者实际都是 400–600 的可变字体。成因是子集化会重写 `fvar`，把「默认实例名」留在了族名字段上。
   CSS 不读这些字段，但字体管理器/安装器会读，会报出一个该文件渲染不出的字重。
   已用 `tools/fonts/fix-name-table.py` 修好（**覆盖与体积零变化**：7764 码位 / 7764 字形不变）。
   v2.2 换字体时已把这条固化为构建参数：`build-subsets.py --family-name "<族名>"`，
   生成出来的子集族名直接正确，不再需要事后修补。
2. 子集化会钳制 `fvar` 的 `wght` 轴并重写 `instances`，因此产物在 OFL 定义下属于 **Modified Version**，
   §3 由此生效（不得使用保留字体名）。经逐份核对上游 OFL 原文：
   Public Sans 与 Geist Mono **未声明任何保留字体名**；Noto Sans SC 的 OFL 是 Adobe 版权、保留名 `'Source'`，
   而子集族名 `Noto Sans SC` 不含 `Source`，故 §3 满足。

**字体工具链**（`tools/fonts/`，此前子集是手工产物、无法复现）：

| 脚本 | 作用 |
