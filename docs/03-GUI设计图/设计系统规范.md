## 1. 色彩

### 1.1 表面（碳墨层级）

| Token | 值 | 用途 |
|---|---|---|
| `--bg-0` | `#0A0D12` | 应用底色（含双色极淡氛围光晕：蓝 75° 上方 / 琥珀 10° 下方，透明度 ≤4.5%） |
| `--bg-1` | `#10141C` | 面板（侧栏/卡片/抽屉） |
| `--bg-2` | `#161B26` | 浮层、卡片内嵌块 |
| `--bg-3` | `#1D2330` | 输入框、悬停态 |
| `--bg-4` | `#242B3A` | 分段选中、更亮表面 |

### 1.2 线与文本

| Token | 值 | 用途 |
|---|---|---|
| `--hairline` | `rgba(255,255,255,.07)` | 常规分隔线 |
| `--hairline-2` | `rgba(255,255,255,.12)` | 强分隔线、输入描边 |
| `--ink-1` | `#E9EDF5` | 主文本（对 `--bg-1` 对比度 ≈13.8:1） |
| `--ink-2` | `#9AA4B8` | 次文本（≈5.9:1，AA 达标） |
| `--ink-3` | `#5F6B82` | 弱文本/标签（仅用于 ≥10px 非关键信息，≈2.9:1，装饰性） |

### 1.3 语义色

| Token | 值 | 语义 | soft 底 |
|---|---|---|---|
| `--accent` | `#E8A33D` | 品牌·琥珀：主按钮、配音模式、空闲倒计时、当前态 | `rgba(232,163,61,.14)` |
| `--teal` | `#4FD6BE` | 译文/完成/术语高亮/VRAM 正常 | `rgba(79,214,190,.12)` |
| `--danger` | `#E5484D` | 危险操作、失败、off-target 徽标 | `rgba(229,72,77,.12)` |
| `--warn` | `#F2B84B` | 警告（下载中/近似达标提示） | `rgba(242,184,75,.1)` |
| `--info` | `#6CA0FF` | 信息态（就绪/格式标签） | `rgba(108,160,255,.12)` |

- 主按钮 `--accent` 上的文字用 `#0A0D12`（对比度 ≈8.9:1）。
- **禁用**：紫色渐变、纯白大面积、彩虹状态色。语义不许混用（琥珀只属于品牌/配音/倒计时，完成一律青绿）。

## 2. 字体

| 角色 | 字体栈 |
|---|---|
| 拉丁正文 | `IBM Plex Sans`（Google Fonts，随 WebView2 内嵌分发时本地打包 woff2） |
| 等宽（时间码/指标/标签） | `IBM Plex Mono` |
| 中文 | `Microsoft YaHei UI` → `思源黑体 CN` → `Noto Sans SC`（系统栈，不打包 CJK 字体） |

| 级 | 规格 |
|---|---|
| Display | 17px / 700（引导页标题） |
| 标题 | 15px / 700（模型名） |
| 正文 | 13-15.5px / 400-600（翻译区 15.5px，行高 1.9——双语阅读舒适） |
| 说明 | 11.5-12.5px / 400 |
| 刻度标签 | IBM Plex Mono 9.5-11px / 500，`letter-spacing .12-.14em`，大写英文 + 中文双写（`历史记录 · HISTORY`）——**签名细节，全站统一** |

## 3. 间距 / 圆角 / 阴影 / 高度

- **间距**：4 的倍数（4/8/12/16/20/26）；面板内边距 16-20px；卡片栅距 16px。
- **圆角**：`--radius-s 6px`（chip/小件）、`--radius-m 10px`（输入/浮块）、`--radius-l 14px`（面板/卡片）；圆形仅用于交换按钮与状态点。
- **阴影**：`--shadow-1 = inset 0 1px 0 rgba(255,255,255,.04), 0 8px 24px rgba(0,0,0,.45)`——暗色主题靠描边+内高光分层，不依赖重投影。
- **高度层级**：bg-1 面板(0) → 下拉/抽屉(10) → 模态(20) → mockup 切换器(100，非产品)。

## 4. 组件规范（与 mockup 一致）

| 组件 | 规范 |
|---|---|
| **按钮** | 高 34px（主操作）/30px（次级）；主=琥珀实底黑字，次=`--bg-3` 底描边，ghost=透明；danger=红描边红字，悬停出现 soft 红底 |
| **Chip** | 等宽字体 10.5px，圆角 99px，6px 状态点在前；状态色映射：运行/完成/off-target 检测通过=teal，运行中/推荐=amber，失败/危险=danger，就绪=blue |
| **开关 Switch** | 36×20px，开=琥珀；关闭态用 `--bg-4` 底 `--ink-2` 圆点 |
| **分段器 Seg** | 容器 `--bg-2` + 2px 内边距；选中项 `--bg-4` 白字（品牌相关选中项用琥珀 soft 底琥珀字） |
| **进度条** | 高 6px 圆角 99px；下载/通用=琥珀渐变(`#E8A33D→#F2C258`)，翻译完成量=青绿渐变 |
| **输入框** | `--bg-3` 底 `--hairline` 描边，聚焦=琥珀描边 `--accent-line(rgba(232,163,61,.38))` |
| **左导航 Rail** | 64px 宽；激活项琥珀图标 + soft 底 + 左缘 2px 琥珀竖条；活动指示点(teal)标注有任务页面 |
| **状态栏** | 40px 高，等宽字体 11px；固定四组信息：模型 chip / VRAM 迷你条 / 空闲倒计时（琥珀）/ 隐私徽章 |
| **空态** | 点阵网格背景（`radial-gradient` 1px 点，24px 网格）+ 居中插画式图标 + 主/副两行文案 + 唯一主动作 |

## 5. 布局与响应式

- 设计基准：1366×768（最小）与 1920×1080（标准）两档。
- 主翻译台三栏 `236 / 1fr / 312`；历史与抽屉可折叠；<1180px 时隐藏侧栏与抽屉（真机中变为抽屉唤出）。
- 字幕工作台 `1.55fr / 1fr`；cue 表格虚拟滚动（可视行 + 上下各 6 行缓冲）。
- 模型卡片三列 → 1380px 以下两列 → 1180px 以下单列。
- 双栏中缝：1px 点状竖虚线（`repeating-linear-gradient`），中央交换按钮悬停旋转 180°——**品牌交互记忆点**。

## 6. 动效

| 场景 | 动效 |
|---|---|
| 页面切换 | 8px 上移淡入 350ms ease（仅新页入场） |
| 流式打字 | 末尾 2px 琥珀光标 caret，1s steps 闪烁；输出字符无逐字动画（由数据流本身驱动） |
| 卡片入场 | 模型中心三卡 stagger 100ms 依次淡入 |
| 交换语言 | 旋转 180°（transform 过渡 200ms） |
| 状态徽标切换 | 背景色 180ms 过渡；禁止弹跳/缩放类夸张动效 |
| 尊重系统 | 实现时监听 `prefers-reduced-motion`，关闭非必要过渡 |

## 7. 可访问性（WCAG 2.1 AA）

- 正文/语义色对比度见 §1.2/1.3 标注，全部 ≥4.5:1；`--ink-3` 仅装饰性小字。
- 全部操作可达：Tab 序 = 左栏导航 → 主内容 → 状态栏；焦点环 2px 琥珀外描边 + 2px 间距。
- 快捷键完整集合见 01 文档 §6.5；Esc 永远取消当前任务/关闭浮层。
- 状态不依赖纯颜色传达：chip 带文字（done/failed/…），off-target 徽标附 tooltip 说明。

## 8. 反模式（禁止项）

- 紫色系与品牌无关；不引入第二个品牌暖色。
- 不使用阴影表达选中（选中=琥珀左缘条 + soft 底）。
- 刻度标签字体只允许 IBM Plex Mono（禁止正文中文用等宽渲染拉丁）。
- 图标仅 lucide-react，线宽 1.8px；禁止混用拟物/填充图标。
- 加载中禁止整页遮罩（仅任务区骨架屏 + 状态栏徽标）。
