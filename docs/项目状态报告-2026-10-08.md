## 一、项目概况

**Index-VT** 是一款运行于 Windows 的全本地 AI 桌面文本翻译工具，基于 Bilibili IndexTeam 开源的 Index-Translate 模型家族（Apache-2.0）与 llama.cpp CUDA 推理栈。

### 技术栈
- **后端**：Go 1.25+ / Wails v2.16 / SQLite (modernc.org)
- **前端**：React 18 / TypeScript 5.7 / Tailwind CSS 4 / Vite 6
- **推理**：llama-server (llama.cpp CUDA)
- **设计**：瑞士国际风格（v2.1）

### 项目规模
- Go 源文件：70 个（39 实现 + 31 测试；上次同步时 60 个是 e0b5aa3 之前的口径）
- 前端源文件：49 个
- UI 组件：23 个原语（`components/ui/` 下 24 个文件含 `index.ts`）
- 页面：6 个（主翻译台、字幕工作台、文档翻译、模型中心、设置、引导页；另有 `_Primitives.tsx` 陈列页）
- 文档：16 个 markdown（设计、执行、验收、spec ×5、plan ×5、ADR ×7、状态报告）

### 发现并已修复的缺陷（6 项）

| # | 级别 | 缺陷 | 症状 / 触发 | 修复 |
|---|---|---|---|---|
| 1 | **High（白屏崩溃）** | `SubtitleWorkbench.tsx` 详情面板 `find(...)!` 非空断言 | 删除最后一条 cue 后 `selIdx` 指向已删条目 → `c.index` 抛 TypeError → 整页白屏 | 渲染守卫（找不到条目显示占位提示）+ `doDeleteCues` 成功后清空选中 |
| 2 | Medium（数据损坏） | 时间 ±100ms 无边界校验 | 连点可造出负时间 / 起止倒挂条目：时间码渲染垃圾（`-1:-1:-1,-100`），导出非法字幕 | 前端钳制（起 ∈ [0, 止-1]、止 ≥ 起+1）+ `edit.go` `UpdateCue` 校验兜底（非负 + 止>起，纯文本补丁不受影响）+ 3 个回归测试 + `tc()` 负值钳 0 |
| 3 | Medium（状态错乱） | `DocTranslate.tsx` 事件未按 docId 过滤 | 翻译中导入新文档：旧文档 `doc:progress`/`doc:done` 覆盖当前进度、`refreshDoc(旧id)` 把显示中的文档换成旧文档 | `docIdRef` 严格匹配（载荷恒带 docId），`doStart`/`doPick` 同步登记 |
| 4 | Low（a11y） | 平移/校准 Modal 裸 `<input>` 无 aria-label | axe 判 critical（与历史 Settings 三裸输入同类）；Modal 关闭态不进门禁扫描故此前未暴露 | 补 `aria-label` |
| 5 | Low（误导提示） | `DocExport` 取消保存仍弹「已导出」 | 用户取消保存对话框 → 假成功 toast，误认为文件已落盘 | 绑定改返回实际路径（空串=取消），前端按返回值决定 toast（mock 本就返回路径，已对齐） |
| 6 | Low（dev-only） | mock 演示文档永不完成 | `?mock&page=doc` 快照 chunk 2 恒 `pending` → 导出按钮永不出现，「导入→翻译→导出」流程走不通、导出 UX 无法被页面级验证覆盖 | `docDemoDone` 同步进 `mockDocSnapshot`，`DocTranslate` 重跑时复位 |

### 安全审查结论：未发现高危漏洞

逐项核查过的边界（均已有防护，无需修改）：
- **命令注入**：`exec.Command("explorer", dir)` 参数化、dir 恒来自 `paths.ModelsDir()/LogsDir()`；`spawn` 走 args 数组无 shell 拼接
- **路径穿越**：`paths.Contains`（AssignUnknown/Delete）+ `ValidateGGUFName`；`SubExport` 的 `OutPath` 由服务端保存对话框覆写，前端传值不生效
- **SQL 注入**：store 全参数化（全仓无 SQL 字符串拼接）
- **下载安全**：fail-closed SHA256（拿不到官方 SUMS 拒绝安装）、续传同源 + ETag 校验 + `.part` 尺寸校验、`maxDownloadBytes` 上限、请求超时齐备
- **XSS**：无 `dangerouslySetInnerHTML`/`innerHTML`/`eval` sink，全部 React 文本渲染
- **崩溃/死锁**：Wails 绑定层入参均有越界/存在性校验；`queueCancel` 并发守卫统一持 `e.mu`；下载/子进程生命周期经 Track A 止血（B1–B31）
